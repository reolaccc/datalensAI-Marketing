# blackout_v2_regression_subset

This folder contains promoted adversarial regression datasets from `blackout_v2`.

These files are safe to run frequently. Use them to check that known semantic bugs do not return, especially:

- CRM campaign or marketing contamination
- generic value fields escalating into revenue or retail meaning
- ops/support summary coverage regressions
- retail Data Summary and Executive Insight alignment

Do not edit the CSV contents when using this folder as a regression fixture.
